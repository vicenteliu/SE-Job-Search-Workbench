# The method, on one page

A job search produces five kinds of material, and most people write them in the wrong order —
resume first, everything else the night before. This workbench reverses it.

```
facts  →  claim check  →  JD teardown  →  questions by intent  →  practice
```

1. **Facts** ([02](02-facts-first.md)). Your career as a list of things that happened, each tagged
   with how far you can stand behind it. This is the only document that never changes to fit a job.
2. **Claim check**. A JD names skills; for each one you record a verdict — hands-on, ramping,
   reviewed-only, lapsed, missing — with the sentence you would actually say about it in the room.
   An honest sentence for a gap is worth more than a blank cell.
3. **JD teardown** ([03](03-resume-vs-jd.md)). One job description, line by line: responsibilities,
   the skills each one really demands, the verdicts, what is missing, and — the part everyone skips —
   *every line mapped to the questions it will provoke.* A 30-line JD yields 60–90 question surfaces.
4. **Questions by intent** ([04](04-questions-by-intent.md)). Those 60–90 surfaces collapse to 25–35
   *intents*, because a JD asks about the same thing from several angles. One card per intent, the
   phrasings recorded as aliases, pointers to the facts and stories that answer it — and **no written
   answers**. The bank stores where an answer comes from; you assemble it when you prepare and say it
   live.
5. **Practice** ([05](05-practice.md)). Out loud, timed, then a critique of *which point you missed*,
   never a score. A score is a number you cannot act on.

The resume comes last, and it is short work by then: bullets chosen from confirmed facts, ordered
for one JD, each citing the fact it came from ([01](01-how-hr-screens.md) says why that shape passes
a screen). A resume built any other way is a set of claims you have not yet been asked to defend.

## Why "nothing invented" is a mechanism, not a promise

Every tool that touches a resume is tempted to make it say more. The temptation is resisted here by
structure rather than by instruction: a bullet has to cite a fact id, a fact has to be confirmed by
you, a gap is a row in a report rather than a rewritten sentence, and a practice run returns missed
points rather than a number. You can still lie on your resume — but not by accident, and not
because a tool did it for you.
