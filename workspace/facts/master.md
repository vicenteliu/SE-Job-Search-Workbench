# Master — the facts

Append-only. One concrete claim per fact. Tags: `VERIFIED` (did it; can be interviewed on it) ·
`EXPOSURE` (touched it; cannot claim ownership) · `INTENT` (want to; have not). A fact is citable
only once `confirmed: yes`.

## Don't say

Things you have decided never to say in an interview, so a talk track can check itself against
them. Examples: the way you will not describe leaving a job; internal names of a former employer's
systems; a tool you have never run described as if you had.
