# Talk-track template — blank skeleton

Copy this, keep the structure, fill from `stories/` and `facts/master.md`. Put this legend at the
top of every generated file:

> Study version: hard words carry **[respelling /IPA/]**; a parallel line in your own language under
> each block if you use one. For the room, use `Spoken-simple` (clean). `/` = small pause,
> `//` = bigger pause, `[brackets]` = cue, not spoken.
> Verdicts: `HANDS-ON` speak with full confidence · `RAMP` the honest boundary · `REVIEW` maps from
> real discipline, no production claim · `LAPSED` "the operations half I still use".

---

## LAYER 1 — Frame sections (any interview, by content)

### 0) Open
> "Hi [name], / thanks for making the time — / really nice to meet you."

### 1) About me (60 s: one identity line + one through-line)
> [one-line identity] + [years] + [the lane] + [the through-line: "I take messy and manual / and make it stable, automated, repeatable"]. // [one flagship proof].

### 2) Why this company (3 reasons, last one forward-looking)
> "A few reasons. // **First** — [lane fit]. // **Second** — [hands-on hook]. // **Third** — [where the company sits in the bigger wave]."

### 3) Why I'm leaving (calm, short, stop)
> [the framing you have decided on, in one or two lines]. [stop]

### 4) Tool stories (LAYER 2 cards go here — pick by JD)

### 5) Honest limits (when a weak spot is pressed)
> [the boundary line for whatever RAMP / REVIEW / LAPSED came up — verbatim from the claim check].

### 6) Logistics
- On-site / work authorization / start date / salary ("fair for the role") / interviewing elsewhere.

### 7) My questions (2–3)
> [role split] / [what success looks like in 6 months] / [team shape] / [next steps].

### 8) Close
> "Thanks [name] — / I really enjoyed this. // Strong fit for me, / and I'm very interested. // Looking forward to next steps."

## LAYER 2 — Story card (four beats; this is the core — never a noun list)

Each tool = ONE card. Keep all four beats. Drop a beat → card not ready.

```
### [Tool name]  ·  verdict: HANDS-ON | RAMP | REVIEW | LAPSED  ·  scope: [one phrase]

🔧 Problem — what was broken / manual / at risk
⚙️ How     — the specific features / workflow you DROVE (API and script over GUI)
🔀 Why     — the migration or trade-off, and the reasoning
📈 Outcome — the measurable result (facts f…) + what it proves about you

🎙️ Spoken (study):
> [English delivery, ≤18 words per line, word[respelling], / pauses, [stage cues]. Four beats woven into one arc.]
> [parallel line in your own language, if you use one]

⚡ 30 s:
> [one or two sentences for fast rounds]

🚧 Honest boundary:
> [one line — what you do NOT claim. Verbatim from the claim check for RAMP / REVIEW / LAPSED.]
```

---

## LAYER 3 — Three depth layers to emit (every time)

1. **Study version** — full, respellings + parallel line (memorise).
2. **Spoken-simple** — clean English, pauses kept, no brackets (read in the room).
3. **30-second** — the ⚡ line of each card, stacked (fast / recruiter rounds).
