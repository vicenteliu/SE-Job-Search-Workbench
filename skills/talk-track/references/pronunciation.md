# Pronunciation notation

How to annotate hard words for spoken delivery. Keeps every talk track consistent.

| Form | When | Example |
|---|---|---|
| `word[RE-spel-ing /IPA/]` | hard common word | `infrastructure[IN-fruh-struk-cher /ˈɪnfrəˌstrʌktʃər/]` |
| `WORD[letters]` | acronym said letter by letter | `RHCE[letters]`, `SCCM[letters]`, `ACL[letters]` |
| `WORD[RAYD]` | acronym said as a word | `RAID[RAYD]`, `SCIM[skim]` |
| `word[RE-spel-ing]` | easy-ish, respelling alone is enough | `VMware[VEE-em-wair]` |

- The respelling is English syllables with CAPS on the stressed syllable. It is for *fast recall in
  the room*, not phonetic precision — keep it readable.
- IPA in `/ /` is the accuracy backstop. Include it for genuinely hard words; skip it when the
  respelling is unambiguous.
- `/` = small pause, `//` = bigger pause, `[brackets]` = stage direction, not spoken.
- Annotate a word **once per section**, the first time it appears — not every time.
- The glossary of *your* words lives in `facts/lexicon.md`. Add to it in the same session a new term
  appears, so the next talk track starts from a bigger glossary.
